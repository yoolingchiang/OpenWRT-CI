#京东云亚瑟 RE-SS-01 / AX1800 Pro —— 无 WiFi 版
#
#【本文件定位：自包含清单】
#结构照搬 uiYzzi 的 openwrt_jdcloud_re-ss-01_ci 思路：一台设备一份配置、内容写全，
#不做「通用层 + 覆盖层」那套 —— 覆盖面小的时候，自包含清单更好读、改动更安全。
#加载链：本文件 → GENERAL.txt → Settings.sh 注入(luci/主题/高通参数) → make defconfig
#
#与 JDCloud-WiFi.txt 的唯一区别：关掉 ath11k 与无线相关包（当纯有线路由 / 外接 AP 用）。
#其余完全一致 —— 两台都是亚瑟、都是 1G RAM + 64G eMMC，能力相同。
#
#为什么必须单独一份而不是共用：同一个 .config 里 CONFIG_PACKAGE_* 是全局的
#（PER_DEVICE_ROOTFS 只分开各机型 rootfs，不分开包集合），WiFi 版要 ath11k、本版不要，
#合成一份就会互相打架。一配置一设备/形态，是这套架构能成立的前提。
#
#源码：VIKINGYFY/immortalwrt 与 LiBwrt/LibWrt 两条线共用这一份（由工作流给 SOURCE/BRANCH）
#硬件：IPQ6000，硬改 1G RAM + 64G eMMC，本配置不出 WiFi

#======================= 三、无 WiFi：显式关掉无线相关包 =======================
#为什么必须显式关：ipq60xx 各机型的 DEFAULT_PACKAGES 里自带 ath11k 与对应固件，
#「没写」不等于「不装」—— 不写 =n 的话 defconfig 会照常用机型默认值把它拉进固件。

CONFIG_PACKAGE_iwinfo=n
#CPU 调频与 WiFi 无关，保留（亚瑟 1G 版跑高负载时有用）
CONFIG_PACKAGE_cpufreq=y
#注意：关掉的是「无线」，不是「NSS」。NSS 数据面卸载（kmod-qca-nss-drv 等）同样来自
#DEFAULT_PACKAGES，有线转发照样能卸载。
#
#ath11k 内存档位（ATH11K_MEM_PROFILE_*）与 NSS 固件版本（NSS_FIRMWARE_VERSION_*）不写在这里：
#两者都是 Kconfig choice，同一份 .config 只能有一个 =y，统一交给 Scripts/Settings.sh 裁定
#（本份是 noWiFi → ath11k 512M 档 + NSS 11.4 固件）。这两组符号只在 LibWrt(6.12) 线存在，
#immortalwrt(6.18) 线没有这两个 choice，脚本会检测并跳过，写在这里对那条线也是无效行。
